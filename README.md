# Supply Network Optimization

Supply chain network design optimization balancing facility location, transportation costs, and capacity constraints.

## 🚀 Tech Stack
- **Languages & Frameworks:** Python, Pyomo, NetworkX, SciPy, Matplotlib
- **Environment:** Python 3.9+

## 📁 Repository Structure
```
├── data/              # Dataset files (raw & processed)
├── notebooks/         # Exploratory Data Analysis & experiments
├── src/               # Source code & modules
│   ├── __init__.py
│   └── main.py        # Entry point script
├── tests/             # Unit and integration tests
├── .gitignore
├── requirements.txt
└── README.md
```

## 🛠️ Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/YOUR_USERNAME/Supply-Network-Optimization.git
cd Supply-Network-Optimization
```

### 2. Create Virtual Environment & Install Dependencies
```bash
python -m venv venv
# On Windows:
venv\Scripts\activate
# On macOS/Linux:
source venv/bin/activate

pip install -r requirements.txt
```

### 3. Run the Project
```bash
python src/main.py
```
